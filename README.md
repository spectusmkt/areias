# Pousada Areias do Peró

Site institucional da Pousada Areias do Peró — Rua Olívia Lopes, 14 B, Peró, Cabo Frio – RJ.

Página única em HTML/CSS/JS puro (sem build), pronta para GitHub Pages ou qualquer hospedagem estática.

- `index.html` — página completa (estilos e scripts embutidos)
- `imagens/` — fotos otimizadas e logo (branca e azul)

## Reservas

Todos os botões de reserva abrem o WhatsApp (+55 22 2041-4623) com mensagem pronta.
A barra de reserva no topo envia check-in, check-out e número de hóspedes.
Para trocar o número, altere `WHATS` no script ao final do `index.html`.
